# Font Design Tools

Small standalone tools for type design workflows.

This folder contains browser-based utilities that complement the Glyphs scripts
in this repository. They are not installed inside Glyphs; open each tool from
its own `index.html` file.

## Tools

- **Glyphs Export Prep**: checks and prepares exported Glyphs data before final
  review.
- **Optical Stem Analyzer**: loads an SVG glyph preview and compares straight
  and curved stem thickness, with optional draggable crossbeam measuring.

## Notes

These tools are designed for quick local use while drawing or reviewing type.
They do not replace optical judgement, but they make repeated measurements much
faster and more consistent.
